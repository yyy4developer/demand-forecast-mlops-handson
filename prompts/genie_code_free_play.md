# Genie Code に頼むときの例文 — 自由時間（`99_your_own_data`）

⭐⭐ **決まった手順はありません。** 例文を出発点に、自分の言葉で自由に頼んでください。

> ⭐ `<CSV>` `<TABLE>` は notebook の出力に置き換えてください。

## ⚠️ コツは 3 つだけ

| | |
|---|---|
| 1 | ⚠️ **1 つずつ頼む**（一度に全部頼むと的が外れます） |
| 2 | ⭐ **質問されたら答える**（それがこの時間の体験です） |
| 3 | ⭐ **おかしければ「〜が違う」と言い直す**（会話で直すのが本来の使い方） |

---

## ⭐⭐ メイン

### ① テーブルを作る

```
<CSV> を見て、<TABLE> にテーブルを作ってください。
列は item_code / channel / ym / qty に揃えて、ym は月末日にしてください。
何行取り込めたかも教えてください。
```

### ② ダッシュボードを作る

```
<TABLE> でダッシュボードを作ってください。日本語のタイトルで。
```

### ③ 意味を付ける（⚠️ ④ の前に）

```
<TABLE> に列コメントを付けて、メトリクスビューも作ってください。
```

⚠️⚠️ **これを飛ばすと Genie Agent の答えの精度が出ません。** `02` で強調したとおりです。

### ④ Genie Agent を作る

```
そのメトリクスビューで Genie Agent を作ってください。日本語で答えるように。
```

---

## ⚠️ おまけ（時間が余ったら）

| | 例文 |
|---|---|
| ⑤ SQL 1 文で予測 | `<TABLE> を ai_forecast で 12 か月先まで予測してください。` |
| ⑥ モデルを作る | `<TABLE> で需要予測モデルを作って、Unity Catalog に登録してください。`<br>⚠️ `「去年と同じ」と比べた結果も見せてください。` |
| ⑦ 予測と精度を残す | `そのモデルで推論して、予測と実績を突き合わせた表を作ってください。` |
| ⑧ 再学習して入れ替え | `最新データで作り直して、良ければ本番と入れ替えてください。` |
| ⑨ 自動実行にする | `⑦ と ⑧ を毎月自動で回すジョブにしてください。` |
| ⑩ 品目ごとに手法 | `品目ごとに向いている予測手法を提案してください。` |

---

## ⚠️ つまずいたときの言い方

| ⚠️ 症状 | ⭐ 言い方 |
|---|---|
| 列の意味を誤解された | 「まず各列が何を表しているか教えてください」から始める |
| 日本語の列名でエラー | 「日本語の列名はバッククォートで囲んでください」 |
| 年月が変換できない | 「年月は `2024年1月` のような形式です。月末日にしてください」 |
| 数量が文字列扱いになる | 「数量に桁区切りが入っています。カンマを除いて数値にしてください」 |
| 日本語が化ける | 「文字コードは Shift_JIS かもしれません」 |
| Genie の答えがおかしい | ⚠️ ③ を飛ばしていませんか |
| 月数が足りないと言われる | ⚠️ モデル作成には各系列 **24 か月以上**必要。⭐ 足りなければ ⑤ を試す |

⭐⭐ **うまくいかない方が学びになります。**
⭐ 「どう頼み直したら通ったか」を持ち帰ってください。
