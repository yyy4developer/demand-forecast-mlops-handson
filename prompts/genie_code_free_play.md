# Genie Code に頼むときの例文 — 自由時間（`99_your_own_data`）

⭐⭐ **テーブル作成からダッシュボード・Genie Agent まで、全部「言葉で頼んで」作らせます。**
⚠️ 自分でコードを書くことが目的ではありません。

> ⭐ `<CSV>` `<SCHEMA>` は notebook の出力に置き換えてください。
> ⚠️ **テーブル名は決めません。** 中身に合わせて Genie Code に付けてもらいます。

## ⚠️ コツは 3 つだけ

| | |
|---|---|
| 1 | ⚠️ **1 つずつ頼む**（一度に全部頼むと的が外れます） |
| 2 | ⭐ **質問されたら答える**（それがこの時間の体験です） |
| 3 | ⭐ **おかしければ「〜が違う」と言い直す**（会話で直すのが本来の使い方） |

---

## ⭐⭐ メイン

### ① まず中身を見てもらう

```
<CSV>
このファイルの中身を見て、各列が何を表しているか教えてください。
```

⭐ **ここから始めるのが効きます。** ⚠️ いきなりテーブルを作らせると列の意味を誤解されます。

### ② テーブルにする

```
では <SCHEMA> にテーブルを作ってください。
テーブル名は中身に合わせて付けてください。
何行取り込めたか、変換できなかった行があるかも教えてください。
```

### ③ ダッシュボードを作る

```
さっき作ったテーブルでダッシュボードを作ってください。日本語のタイトルで。
```

### ④ 意味を付ける（⚠️ ⑤ の前に）

```
そのテーブルに列コメントを付けて、メトリクスビューも作ってください。
```

⚠️⚠️ **これを飛ばすと Genie Agent の答えの精度が出ません。** `02` で強調したとおりです。

### ⑤ Genie Agent を作る

```
そのメトリクスビューで Genie Agent を作ってください。日本語で答えるように。
```

# ⚠️ ここから下はおまけ

⭐ **時間が余った人向け**です。⭐ どれも「さっき作ったテーブルで」と言えば通じます。

| やりたいこと | ⭐ 言い方 |
|---|---|
| グラフを足す | 「〇〇の推移が見たいのでグラフを足して」 |
| 気になることを聞く | Genie Agent に業務の言葉で質問してみる |
| データを足す | 別の CSV も置いて「これも結合して」 |

## ⚠️ 時系列データ（日付と数量がある）の場合

⭐ ここまで行けます。

| やりたいこと | ⭐ 言い方 |
|---|---|
| SQL 1 文で予測 | 「ai_forecast で 12 か月先まで予測して」 |
| モデルを作る | 「予測モデルを作って Unity Catalog に登録して」<br>⚠️ 「去年と同じと比べた結果も見せて」 |
| 精度を残す | 「予測と実績を突き合わせた表を作って」 |
| 自動実行にする | 「毎月これを回すジョブにして」 |

---

## ⚠️ つまずいたときの言い方

| ⚠️ 症状 | ⭐ 言い方 |
|---|---|
| 列の意味を誤解された | ⭐ **① をやり直す** — 「まず各列が何を表しているか教えて」 |
| 日本語の列名でエラー | 「日本語の列名はバッククォートで囲んでください」 |
| 日付が変換できない | ⭐ **元の値をそのまま見せて**「この形式です」と伝える |
| 数値が文字列扱いになる | 「桁区切りが入っています。カンマを除いて数値にしてください」 |
| 日本語が化ける | 「文字コードは Shift_JIS かもしれません」 |
| Genie の答えがおかしい | ⚠️ ④ のメタデータを飛ばしていませんか |
| 行が減っている / 増えている | 「取り込めなかった行と、重複していた行を教えて」 |
| ⚠️ 予測で「データが足りない」 | ⚠️ 予測には各系列 **24 か月以上**必要。⭐ 短ければ `ai_forecast` を試す |

⭐⭐ **うまくいかない方が学びになります。**
⭐ 「どう頼み直したら通ったか」を持ち帰ってください。
