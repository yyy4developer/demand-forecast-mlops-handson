# Genie Code に投げるプロンプト — MMF (Many Models Forecasting)

`08_mmf_genie_code` で使います。

> ⚠️⚠️ **1 回の指示では終わりません。**
> MMF のスキルは「カタログはどこ？」「何を予測したい？」「欠測はどう扱う？」と
> **必ず確認しながら進む**設計になっています。
> ⭐ この「AI が要件をヒアリングしてくる」こと自体が体験の中身です。

---

## ① 開始

```
MMF (Many Models Forecasting) を使って需要予測をしたい。

- カタログ: <カタログ名>
- スキーマ: <あなたのスキーマ>
- ユースケース名: scm
- 元データ: <カタログ名>.<あなたのスキーマ>.fct_shipments
- 予測対象: 品目 × チャネルごとの月次出荷数量 (qty)
- 系列 ID: item_code と channel の組み合わせ
- 日付列: ym （月末日で入っています）
- 予測期間: 18 か月先
- 頻度: 月次
```

## ② AI が聞いてくることへの答え方

| 聞かれること | ⭐ 答え方 |
|---|---|
| カタログとスキーマ | ①に書いたとおり |
| **何を予測したいのか（背景）** | 「産業用機器とその消耗品の月次需要を 18 か月先まで予測し、欠品と過剰在庫を減らしたい。少量多品種で、出ない月がある品目や、海外向けに大口の山が立つ品目が多い」 |
| 欠測している月の扱い | 「欠測月は 0 とする（出荷実績がない = その月は出荷ゼロ）」 |
| ⚠️ **異常値の扱い** | ⭐ **「大口のスパイクは実需なので丸めない」** |
| 次の手順に進むか | 「進んでください」 |

### ⚠️ 異常値の質問は、わざと考えてほしいところ

「外れ値は丸めますか？」と聞かれると「はい」と答えたくなります。
⚠️ でもこのデータの大口スパイクは、海外代理店の先行注文という**実需**です。
丸めると、**いちばん備えたい需要の山が予測から消えます**。

⭐ 「何が異常で、何が実需か」はデータだけでは決められません。
業務を知っている人が決めるところで、AI が聞いてくるのはまさにそれです。

## ③ ⭐⭐ いちばんの見せ場

```
/profile-and-classify-series
```

系列の性質を統計的に調べて、「予測しやすい系列」と「予測しにくい系列」に分け、
予測しにくい系列の扱いを **3 択**で聞いてきます。

| 選択肢 | 内容 |
|---|---|
| A. 全部一緒に扱う | 予測しにくい系列も同じモデルで扱う |
| ⭐⭐ **B. 単純なルールに退避** | **「去年と同じ」「平均」「ゼロ」などを当てる** |
| C. 別パイプライン | 予測しにくい系列だけ別扱いで本格的に回す |

⭐ **B を選び、「去年と同じ（Seasonal Naive）」を指定してください。**

> ⭐⭐ **持ち帰ってほしいのはこれです。**
> **「当てにいかない」という判断が、標準機能として用意されている。**
>
> 予測モデルの話は「どう精度を上げるか」に向かいがちですが、実務では
> **当たらない品目を見切って単純な運用に寄せる**方が正しいことがあります。

## ④ 以降の流れ（時間があれば）

```
/provision-forecasting-resources
```
→ どのモデルを試すか、どんな計算資源を使うかを聞かれます。
⭐ **CPU だけで動くモデル**を選べば GPU は不要です:
`StatsForecastAutoETS` / `AutoTheta` / `AutoArima` / `SKTimeProphet` /
間欠需要向け (`CrostonSBA` など) / `MLForecastLGBM`

```
/execute-mmf-forecast
```
→ ⚠️ ここから 10〜30 分かかります。

```
/post-process-and-evaluate
```
→ ⭐ 系列ごとのベストモデルが `scm_best_models` にまとまります。

## ⚠️ 事前準備（講師向け）

参加者全員のフォルダにスキルを配置しておく必要があります。
配置していないと、MMF のスキルが読み込まれず AI が勝手に進みます。

```bash
# MMF のリポジトリに公式のインストーラがあります
python skills/install.py

# または手動で
databricks workspace import-dir skills/databricks-skills/many-model-forecasting \
  /Users/${USER}/.assistant/skills --overwrite
databricks workspace import skills/assistant_instructions.md \
  /Users/${USER}/.assistant_instructions.md --format AUTO --language MARKDOWN --overwrite
```

⚠️ `assistant_instructions.md` を忘れると、スキルの手順が無視されます。
